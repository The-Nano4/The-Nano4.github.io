Project Overview

We chose to do this project because we felt it was important to give astronauts a way to ask questions and receive accurate, step-by-step instructions on how to fix or handle situations with little or no human assistance. The AI should be able to provide instructions on how to repair damage to the aircraft and assist with medical needs or supplies.

Our project is a small-scale model of a server farm designed to represent how computers could work together in NASA’s Gateway Space Station. We use NVIDIA Jetson Nano boards that connect in a network to multiple servers working as one. These mini computers share tasks, process data, and communicate with each other just like real servers in space would manage information, communication, and life support systems.

  • Nano4 is a low power AI cluster built with NVIDIA Jetson Nanos.
    • Instead of one big computer, we use several smaller ones working together. This helps the AI run faster.
    • It’s a better way to run AI where power and space is limited. This reduces power and space usage so more resources can be used for more important systems.

Problem Statement

The current AI requires high power of GPU’s, and large cooling systems. This makes running LLMs impractical in the space environment such as spacecraft where power, cooling, and technology are limited.

System Design

NVIDIA Jetson Nano and Raspberry Pi hardware

  • Distributed computing across multiple nodes
  • LLAMA (3B parameters)
  • Run under a 60W power limit

Progress & Results
